# Agent Context: Physical AI & Humanoid Robotics Textbook

## Technologies Used

### Docusaurus
- Version: 3.x
- Purpose: Static site generator for documentation
- Configuration: TypeScript support enabled
- Key files: docusaurus.config.js, sidebars.js, package.json

### ROS 2 (Robot Operating System 2)
- Distribution: Humble Hawksbill LTS
- Purpose: Middleware for robotics applications
- Python library: rclpy for Python integration
- Key concepts: nodes, topics, services, actions

### Gazebo
- Purpose: Robot simulation environment
- Integration: Works with ROS 2 for simulation
- Versions: Classic or Garden supported

### Python 3.8
- Purpose: Primary scripting language for ROS 2 nodes
- Compatibility: Required for ROS 2 Humble Hawksbill
- Libraries: rclpy, standard library

### Markdown/MDX
- Purpose: Content format for Docusaurus
- Extensions: MDX for React components in Markdown
- Structure: Frontmatter for metadata

## Project Structure
- frontend/: Docusaurus application directory
- frontend/docs/: Documentation content organized by modules
- frontend/src/: Custom React components
- frontend/static/: Static assets

## Module Organization
- Module 1: The Robotic Nervous System (ROS 2)
- Module 2: Simulation and Perception
- Module 3: Perception and Computer Vision
- Module 4: Advanced Control and VLA
- Capstone: Comprehensive project integrating all concepts

## Educational Standards
- Readability: Flesch-Kincaid grade 10-14
- Target audience: Undergraduate and graduate students
- Prerequisites: Basic Python programming knowledge
- Content length: 3,000-4,000 words per module (Module 1)
