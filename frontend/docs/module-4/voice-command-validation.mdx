# Voice Command Processing Validation

## Overview
This document provides validation procedures and scenarios for the voice command processing system. The validation ensures that the speech-to-text conversion accurately processes voice commands from students and converts them to text output that can be processed by subsequent components.

## Validation Strategy

### Acceptance Criteria
1. Speech recognition accuracy: >85% in quiet environment
2. Confidence scoring: Properly reflects recognition quality
3. Latency: &lt;200ms from speech to text conversion
4. Noise tolerance: Maintains >70% accuracy with moderate background noise
5. Activation detection: Correctly identifies activation phrase in 95%+ of attempts

### Validation Environment
- **Hardware**: RTX-capable workstation with functional microphone
- **Software**: ROS 2 Humble, Isaac Sim, VLA system components
- **Environment**: Controlled acoustic environment with option for noise introduction
- **Test materials**: Pre-recorded audio samples, real-time speech input

## Test Scenarios

### Scenario 1: "Go to the kitchen" - Primary Validation

#### Test Objective
Validate that the system can accurately recognize the command "Go to the kitchen" with sufficient confidence for downstream processing.

#### Test Steps
1. Ensure the system is in IDLE state
2. Speak the activation phrase "hey robot" clearly
3. Pause briefly (system should transition to LISTENING)
4. Speak "Go to the kitchen" clearly and at normal pace
5. Verify system transitions through PROCESSING → PLANNING states
6. Check that recognized text matches expected command
7. Verify confidence score is above threshold (>0.5)
8. Confirm command is published to `/vla/voice_command` topic

#### Expected Results
- Activation phrase detected: ✓
- Command recognized: "Go to the kitchen"
- Confidence score: >0.7 (in quiet environment)
- State transitions: IDLE → LISTENING → PROCESSING → PLANNING
- Message published: ✓ to `/vla/voice_command`
- Processing latency: &lt;200ms

### Automated Validation Script
```python
import unittest
import time
from typing import Dict, List

class VoiceCommandValidator:
    def __init__(self, voice_processor, state_machine):
        self.voice_processor = voice_processor
        self.state_machine = state_machine
        self.validation_results = []

    def run_comprehensive_validation(self) -> Dict[str, any]:
        """
        Run comprehensive validation tests
        """
        results = {
            'accuracy_tests': self.run_accuracy_tests(),
            'latency_tests': self.run_latency_tests(),
            'robustness_tests': self.run_robustness_tests(),
            'integration_tests': self.run_integration_tests()
        }

        # Calculate overall pass/fail
        all_passed = all(
            test['passed'] for category in results.values()
            for test in category
        )

        return {
            'overall_result': 'PASS' if all_passed else 'FAIL',
            'results': results,
            'summary': self.generate_summary(results)
        }

    def run_accuracy_tests(self) -> List[Dict[str, any]]:
        """
        Run accuracy-focused validation tests
        """
        test_cases = [
            {'command': 'go to the kitchen', 'expected': 'go to the kitchen'},
            {'command': 'find the red ball', 'expected': 'find the red ball'},
            {'command': 'pick up the cup', 'expected': 'pick up the cup'},
            {'command': 'move to living room', 'expected': 'move to living room'}
        ]

        results = []
        for test_case in test_cases:
            result = self.test_single_command(
                test_case['command'],
                test_case['expected']
            )
            results.append({
                'test_name': f"Accuracy test for '{test_case['command']}'",
                'passed': result['accuracy'] > 0.85,  # 85% threshold
                'details': result
            })

        return results

    def run_latency_tests(self) -> List[Dict[str, any]]:
        """
        Run latency-focused validation tests
        """
        # Generate multiple test signals
        test_signals = []
        for i in range(10):
            signal = self.generate_test_signal(f"test command {i}")
            test_signals.append(signal)

        # Measure processing time for each
        latencies = []
        for signal in test_signals:
            start_time = time.time()
            self.process_signal(signal)
            end_time = time.time()
            latencies.append((end_time - start_time) * 1000)  # Convert to ms

        avg_latency = sum(latencies) / len(latencies)

        return [{
            'test_name': 'Latency test',
            'passed': avg_latency < 200,  # 200ms threshold
            'details': {
                'average_latency_ms': avg_latency,
                'max_latency_ms': max(latencies),
                'min_latency_ms': min(latencies),
                'latencies_ms': latencies
            }
        }]

    def run_robustness_tests(self) -> List[Dict[str, any]]:
        """
        Run robustness-focused validation tests
        """
        results = []

        # Test with various noise levels
        for snr_db in [20, 15, 10]:
            noisy_signal = self.add_noise_to_signal(
                self.generate_test_signal("go to kitchen"),
                snr_db
            )

            recognition_result = self.process_signal(noisy_signal)
            accuracy = self.calculate_recognition_accuracy(
                recognition_result,
                "go to kitchen"
            )

            results.append({
                'test_name': f'Noise tolerance test (SNR: {snr_db}dB)',
                'passed': accuracy > 0.70,  # 70% threshold
                'details': {
                    'snr_db': snr_db,
                    'accuracy': accuracy,
                    'recognized_text': recognition_result
                }
            })

        return results

    def run_integration_tests(self) -> List[Dict[str, any]]:
        """
        Run integration-focused validation tests
        """
        results = []

        # Test complete state machine flow
        initial_state = self.state_machine.current_state

        # Simulate the complete flow for "Go to the kitchen"
        self.voice_processor._on_command_received("go to the kitchen", 0.8)

        # Verify state transitions occurred properly
        expected_sequence = ['PROCESSING', 'PLANNING']
        actual_states = [s.value for s in self.state_machine.state_history if s.value in expected_sequence]

        passed = actual_states == expected_sequence

        results.append({
            'test_name': 'Integration test for "Go to the kitchen"',
            'passed': passed,
            'details': {
                'initial_state': initial_state.value,
                'expected_sequence': expected_sequence,
                'actual_sequence': actual_states,
                'state_history': [s.value for s in self.state_machine.state_history]
            }
        })

        return results

    def generate_summary(self, results: Dict[str, List]) -> Dict[str, any]:
        """
        Generate a summary of validation results
        """
        total_tests = 0
        passed_tests = 0

        for category, tests in results.items():
            for test in tests:
                total_tests += 1
                if test['passed']:
                    passed_tests += 1

        return {
            'total_tests': total_tests,
            'passed_tests': passed_tests,
            'failed_tests': total_tests - passed_tests,
            'pass_rate': passed_tests / total_tests if total_tests > 0 else 0
        }

    def generate_test_signal(self, text: str):
        """
        Generate a test audio signal for the given text
        """
        # In a real implementation, this would generate actual audio
        # For validation purposes, we'll return a placeholder
        return f"signal_for_{text.replace(' ', '_')}"

    def process_signal(self, signal):
        """
        Process an audio signal through the system
        """
        # In a real implementation, this would process the actual signal
        # For validation, we'll return a simulated result
        if "kitchen" in signal:
            return "go to the kitchen"
        elif "ball" in signal:
            return "find the red ball"
        else:
            return "unknown command"

    def add_noise_to_signal(self, signal, snr_db: float):
        """
        Add noise to a signal at the specified SNR
        """
        # Placeholder implementation
        return f"{signal}_with_{snr_db}db_noise"

    def calculate_recognition_accuracy(self, recognized: str, expected: str) -> float:
        """
        Calculate the accuracy of recognition
        """
        # Simple word overlap calculation
        rec_words = set(recognized.lower().split())
        exp_words = set(expected.lower().split())

        if not rec_words and not exp_words:
            return 1.0
        if not rec_words or not exp_words:
            return 0.0

        intersection = len(rec_words.intersection(exp_words))
        union = len(rec_words.union(exp_words))

        return intersection / union
```

## Validation Reports

### Daily Validation Report Template
```python
def generate_daily_validation_report():
    """
    Generate a daily validation report
    """
    validator = VoiceCommandValidator(voice_processor, state_machine)
    results = validator.run_comprehensive_validation()

    report = f"""
VOICE COMMAND PROCESSING - DAILY VALIDATION REPORT
==================================================

Date: {time.strftime('%Y-%m-%d %H:%M:%S')}
System: VLA Voice Command Processor
Environment: {get_system_info()}

OVERALL RESULT: {results['overall_result']}

SUMMARY:
- Total Tests: {results['summary']['total_tests']}
- Passed: {results['summary']['passed_tests']}
- Failed: {results['summary']['failed_tests']}
- Pass Rate: {results['summary']['pass_rate']:.2%}

BREAKDOWN BY CATEGORY:
"""

    for category, tests in results['results'].items():
        report += f"\n{category.upper()}:\n"
        for test in tests:
            status = "PASS" if test['passed'] else "FAIL"
            report += f"  - {test['test_name']}: {status}\n"

    report += f"\nRECOMMENDATIONS:\n"
    if results['summary']['pass_rate'] < 0.95:
        report += "  - Investigate failing tests\n"
        report += "  - Consider system adjustments\n"
    else:
        report += "  - System performing within acceptable parameters\n"

    return report

# Generate and save report
report_content = generate_daily_validation_report()
with open(f"validation_report_{time.strftime('%Y%m%d_%H%M%S')}.txt", 'w') as f:
    f.write(report_content)
```
