# Accessibility Features for Voice-First Interface

## Overview

This document outlines the accessibility features implemented in the Vision-Language-Action (VLA) system's voice-first interface. The system is designed to be inclusive and accessible to users with diverse abilities, ensuring that all students can effectively interact with the robotic system regardless of their physical or sensory capabilities.

## Accessibility Principles

The VLA system follows these core accessibility principles:

### 1. Multiple Input Modalities
- Voice commands as primary input
- Text-based fallback for voice recognition
- Visual feedback and confirmation
- Alternative interaction methods

### 2. Flexible Interaction
- Adjustable sensitivity for voice activation
- Multiple activation phrases
- Alternative command formulations
- Error recovery and correction mechanisms

### 3. Clear Feedback
- Audio confirmation of recognized commands
- Visual status indicators
- Progress updates during execution
- Clear error messages

```python
class VoiceCommandCustomizer:
    def __init__(self):
        self.user_command_mappings = {}
        self.activation_phrases = ['hey robot', 'robot', 'start', 'listen']

    def add_custom_command_mapping(self, user_id: str, custom_phrase: str, system_command: str):
        """
        Allow users to define custom voice commands
        """
        if user_id not in self.user_command_mappings:
            self.user_command_mappings[user_id] = {}

        self.user_command_mappings[user_id][custom_phrase] = system_command
        return True

    def get_system_command(self, user_id: str, voice_input: str) -> str:
        """
        Map user's voice input to system command
        """
        # Check user's custom commands first
        if user_id in self.user_command_mappings:
            for custom_phrase, system_cmd in self.user_command_mappings[user_id].items():
                if self._fuzzy_match(voice_input, custom_phrase):
                    return system_cmd

        # Fall back to default commands
        return self._match_default_command(voice_input)

    def _fuzzy_match(self, input_text: str, expected_phrase: str, threshold: float = 0.8) -> bool:
        """
        Perform fuzzy matching for voice input
        """
        from difflib import SequenceMatcher
        similarity = SequenceMatcher(None, input_text.lower(), expected_phrase.lower()).ratio()
        return similarity >= threshold

    def _match_default_command(self, voice_input: str) -> str:
        """
        Match voice input to default system commands
        """
        # Implementation would match to default commands
        return voice_input  # Simplified for example
```

### Text-Based Command Interface

```python
class TextCommandInterface:
    def __init__(self, vla_system):
        self.vla_system = vla_system
        self.command_history = []

    def process_text_command(self, command_text: str, user_id: str = None) -> dict:
        """
        Process a text-based command as an alternative to voice
        """
        # Validate command
        validation_result = self._validate_command(command_text)
        if not validation_result['valid']:
            return {
                'success': False,
                'error': validation_result['error'],
                'command_type': 'text'
            }

        # Process command through VLA pipeline
        try:
            # Convert text command to same format as voice command
            result = self.vla_system.process_command(command_text, confidence=1.0)

            # Log command for history
            self.command_history.append({
                'user_id': user_id,
                'command': command_text,
                'timestamp': time.time(),
                'result': result,
                'input_type': 'text'
            })

            return {
                'success': True,
                'result': result,
                'command_type': 'text'
            }
        except Exception as e:
            return {
                'success': False,
                'error': str(e),
                'command_type': 'text'
            }

    def _validate_command(self, command_text: str) -> dict:
        """
        Validate text command syntax and content
        """
        if not command_text or len(command_text.strip()) < 3:
            return {
                'valid': False,
                'error': 'Command too short'
            }

        if len(command_text) > 200:
            return {
                'valid': False,
                'error': 'Command too long'
            }

        # Check for potentially harmful commands
        if self._contains_harmful_content(command_text):
            return {
                'valid': False,
                'error': 'Command contains inappropriate content'
            }

        return {
            'valid': True,
            'error': None
        }

    def _contains_harmful_content(self, text: str) -> bool:
        """
        Check for potentially harmful content in command
        """
        harmful_keywords = [
            'inappropriate', 'harmful', 'dangerous', 'damage', 'destroy'
        ]

        text_lower = text.lower()
        for keyword in harmful_keywords:
            if keyword in text_lower:
                return True
        return False

    def get_command_suggestions(self, partial_command: str) -> list:
        """
        Provide command suggestions as user types
        """
        all_commands = [
            'go to the kitchen',
            'find the red ball',
            'pick up the cup',
            'move to the living room',
            'navigate to the table',
            'detect objects',
            'grasp object',
            'release object'
        ]

        suggestions = []
        for cmd in all_commands:
            if partial_command.lower() in cmd.lower():
                suggestions.append(cmd)

        return suggestions[:5]  # Return top 5 suggestions
```

```python
class MultiModalFeedback:
    def __init__(self):
        self.audio_feedback_enabled = True
        self.visual_feedback_enabled = True
        self.haptic_feedback_available = False  # If supported by device

    def provide_command_confirmation(self, command: str, confidence: float) -> dict:
        """
        Provide multi-modal confirmation of received command
        """
        feedback = {
            'audio': self._generate_audio_confirmation(command, confidence),
            'visual': self._generate_visual_confirmation(command, confidence),
            'haptic': self._generate_haptic_confirmation() if self.haptic_feedback_available else None
        }

        return feedback

    def _generate_audio_confirmation(self, command: str, confidence: float) -> str:
        """
        Generate audio confirmation message
        """
        if confidence > 0.9:
            return f"Got it, I'll {command}. Starting now."
        elif confidence > 0.7:
            return f"Processing {command}. Please wait."
        else:
            return f"I heard {command}, but I'm not completely sure. Could you repeat that?"

    def _generate_visual_confirmation(self, command: str, confidence: float) -> dict:
        """
        Generate visual confirmation elements
        """
        return {
            'command_display': f"Command: {command}",
            'confidence_meter': self._create_confidence_meter(confidence),
            'status_icon': self._get_status_icon(confidence),
            'progress_indicator': 'Starting...' if confidence > 0.7 else 'Uncertain'
        }

    def _create_confidence_meter(self, confidence: float) -> str:
        """
        Create visual confidence meter
        """
        filled_blocks = int(confidence * 10)
        empty_blocks = 10 - filled_blocks
        return f"[{'█' * filled_blocks}{'░' * empty_blocks}] {confidence:.1%}"

    def _get_status_icon(self, confidence: float) -> str:
        """
        Get appropriate status icon based on confidence
        """
        if confidence > 0.9:
            return "✅"  # High confidence
        elif confidence > 0.7:
            return "🤔"  # Medium confidence
        else:
            return "❓"  # Low confidence
```

```python
class AccessibleErrorHandler:
    def __init__(self):
        self.error_types = {
            'recognition_failure': {
                'audio': 'I couldn\'t understand your command. Could you please repeat it?',
                'visual': 'Command not recognized. Please try again.',
                'suggestions': ['Speak more clearly', 'Reduce background noise', 'Try a different phrase']
            },
            'execution_failure': {
                'audio': 'I couldn\'t complete that task. The robot encountered an issue.',
                'visual': 'Task execution failed. The robot may need assistance.',
                'suggestions': ['Check for obstacles', 'Verify robot is powered on', 'Try a different command']
            },
            'communication_timeout': {
                'audio': 'I\'m having trouble connecting. Please wait while I try again.',
                'visual': 'Communication timeout. Retrying connection...',
                'suggestions': ['Check network connection', 'Wait for retry', 'Use text interface']
            }
        }

    def generate_error_response(self, error_type: str, original_command: str = None) -> dict:
        """
        Generate accessible error response
        """
        if error_type in self.error_types:
            error_info = self.error_types[error_type]

            return {
                'audio_message': error_info['audio'],
                'visual_message': error_info['visual'],
                'suggestions': error_info['suggestions'],
                'alternative_inputs': self._suggest_alternative_inputs(error_type),
                'retry_option': self._get_retry_option(error_type, original_command)
            }
        else:
            return {
                'audio_message': 'An unexpected error occurred. Please try again.',
                'visual_message': 'Error: Unknown error occurred',
                'suggestions': ['Try again', 'Use text interface', 'Contact support'],
                'alternative_inputs': ['text_input', 'button_interface'],
                'retry_option': True
            }

    def _suggest_alternative_inputs(self, error_type: str) -> list:
        """
        Suggest alternative input methods based on error type
        """
        if error_type == 'recognition_failure':
            return ['text_input', 'simplified_command', 'visual_selection']
        elif error_type == 'execution_failure':
            return ['manual_control', 'simplified_task', 'supervisor_assistance']
        else:
            return ['text_input', 'mobile_app', 'supervisor_assistance']

    def _get_retry_option(self, error_type: str, original_command: str = None) -> bool:
        """
        Determine if retry option should be offered
        """
        # Don't auto-retry for recognition failures, let user retry
        if error_type == 'recognition_failure':
            return False
        # Retry for communication timeouts
        elif error_type == 'communication_timeout':
            return True
        # For execution failures, it depends on the command
        else:
            return True
```

## Compliance and Standards

### WCAG Compliance Features

The VLA system implements features to meet WCAG 2.1 AA standards:

1. **Perceivable**
   - Text alternatives for non-text content
   - Adaptable interface that works with assistive technologies
   - Distinguishable visual elements with sufficient contrast

2. **Operable**
   - Keyboard accessible interface
   - Enough time to read and use content
   - Seizure and physical reaction considerations

3. **Understandable**
   - Understandable information and UI operations
   - Input assistance to help users avoid mistakes

4. **Robust**
   - Compatible with assistive technologies
   - Maximizes compatibility with current and future user tools
