# Module 2: The Digital Twin (Gazebo & Unity)

## Overview

Welcome to Module 2 of the Physical AI & Humanoid Robotics textbook. This module introduces you to physics-based robot simulation using Gazebo and high-fidelity visualization using Unity. You'll learn how to simulate physics, collisions, gravity, and sensors (LiDAR, depth cameras, IMUs), and how to build interactive robot environments.

## Learning Objectives

By the end of this module, you will be able to:

- Set up and run a Gazebo simulation environment
- Demonstrate accurate physics behavior: gravity, collisions, rigid body dynamics
- Create or import URDF/SDF humanoid models into Gazebo
- Simulate LiDAR, RGB-D cameras, and IMU sensors with correct data streams
- Produce a Unity scene with humanoid visualization and basic human-robot interaction
- Verify that all examples run on Ubuntu 22.04 with ROS 2 integration

## Prerequisites

Before starting this module, you should have:

- Completed Module 1 and understand ROS 2 fundamentals
- Basic knowledge of Ubuntu 22.04 environment
- Understanding of robot kinematics and dynamics concepts

This module should take approximately 1 week to complete, depending on your prior experience with simulation tools.

## Module Summary

This module covered the fundamentals of creating digital twins for robotics applications using Gazebo and Unity. You've learned how to:

- Set up and configure Gazebo simulation environments with accurate physics
- Implement physics simulation with gravity, collisions, and rigid body dynamics
- Simulate various robot sensors including LiDAR, RGB-D cameras, and IMUs
- Create high-fidelity visualizations in Unity with ROS 2 integration
- Integrate physics simulation with sensor simulation for comprehensive robot modeling
- Apply performance optimization techniques for academic hardware

Through the progressive exercises, you've gained hands-on experience with physics-only, sensor-only, and integrated simulation scenarios, building your understanding from basic concepts to complex integrated systems.
