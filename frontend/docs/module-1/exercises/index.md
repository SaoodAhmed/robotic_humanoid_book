# Module 1 Exercises

This section contains practical exercises for Module 1: The Robotic Nervous System (ROS 2). These exercises are designed with progressive complexity to help you apply the concepts learned in this module.

## Exercise Overview

Complete the following exercises to reinforce your understanding of ROS 2 concepts:

- [Exercise 1: Basic Node Communication](./exercise-1.md) - Learn to create publisher and subscriber nodes
- [Exercise 2: Intermediate Node Communication and URDF Modeling](./exercise-2.md) - Work with sensor data and robot models
- [Exercise 3: Advanced Integration - Python Agents with ROS 2 Controllers](./exercise-3.md) - Integrate AI agents with robot controllers

Each exercise includes step-by-step instructions, expected outcomes, and troubleshooting tips to ensure your success.
