# Module 1: The Robotic Nervous System (ROS 2)

## Overview

Welcome to Module 1 of the Physical AI & Humanoid Robotics textbook. This module introduces you to ROS 2 (Robot Operating System 2), which serves as the "nervous system" for humanoid robots. You'll learn the core concepts of ROS 2 middleware and how it enables communication between different components of a humanoid robot control system.

## Learning Objectives

By the end of this module, you will be able to:

- Understand the fundamental concepts of ROS 2 including nodes, topics, services, and actions
- Create and run ROS 2 nodes for basic robot behaviors
- Implement communication between nodes via topics, services, and actions
- Integrate Python agents with ROS 2 controllers using rclpy
- Design a simple URDF humanoid robot description and visualize it in simulation

## Prerequisites

Before starting this module, you should have:

- Basic Python programming knowledge
- Understanding of fundamental programming concepts
- Familiarity with command-line interfaces

## Module Structure

This module is organized into the following sections:

1. [ROS 2 Basics](./ros2-basics.md) - Introduction to ROS 2 concepts and architecture
2. [Nodes, Topics, and Services](./nodes-topics-services.md) - Detailed exploration of ROS 2 communication patterns
3. [Python Integration with rclpy](./rclpy-integration.md) - Using Python with ROS 2
4. [URDF Modeling](./urdf-modeling.md) - Creating robot descriptions with URDF
5. [Exercises](./exercises/) - Practical exercises with progressive complexity

## Estimated Time

This module should take approximately 1 week to complete, depending on your prior experience with robotics concepts.

## What's Next

After completing this module, you'll have a solid foundation in ROS 2 concepts and be ready to explore simulation and perception systems in Module 2.
