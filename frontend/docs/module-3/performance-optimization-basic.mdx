## Monitoring and Profiling

### Performance Monitoring

Implement performance monitoring in your scenes:
```python
import time
import carb.profiler

class PerformanceMonitor:
    """Performance monitoring class for Isaac Sim"""

    def __init__(self):
        self.frame_times = []
        self.fps_history = []
        self.start_time = time.time()

    def start_frame(self):
        """Start timing a frame"""
        self.frame_start = time.time()

    def end_frame(self):
        """End timing a frame and calculate FPS"""
        frame_time = time.time() - self.frame_start
        self.frame_times.append(frame_time)

        # Calculate FPS
        fps = 1.0 / frame_time if frame_time > 0 else 0
        self.fps_history.append(fps)

        # Keep only the last 100 measurements
        if len(self.frame_times) > 100:
            self.frame_times.pop(0)
            self.fps_history.pop(0)

        return fps

    def get_average_fps(self):
        """Get average FPS over recent frames"""
        if self.fps_history:
            return sum(self.fps_history) / len(self.fps_history)
        return 0

    def get_min_fps(self):
        """Get minimum FPS over recent frames"""
        if self.fps_history:
            return min(self.fps_history)
        return 0

    def get_performance_report(self):
        """Get a comprehensive performance report"""
        avg_fps = self.get_average_fps()
        min_fps = self.get_min_fps()
        max_fps = max(self.fps_history) if self.fps_history else 0

        report = {
            'average_fps': avg_fps,
            'minimum_fps': min_fps,
            'maximum_fps': max_fps,
            'target_met': avg_fps >= 30,
            'total_frames': len(self.fps_history),
            'elapsed_time': time.time() - self.start_time
        }

        return report
```

## Troubleshooting Performance Issues

### Common Performance Bottlenecks

#### GPU Bottlenecks
- **Symptoms**: Low FPS, GPU usage at 100%
- **Solutions**:
  - Reduce rendering resolution
  - Lower texture quality
  - Simplify materials
  - Reduce shadow quality

#### CPU Bottlenecks
- **Symptoms**: High CPU usage, inconsistent frame times
- **Solutions**:
  - Reduce scene complexity
  - Optimize physics calculations
  - Reduce object count
  - Use object pooling

#### Memory Issues
- **Symptoms**: Slow loading, crashes, high memory usage
- **Solutions**:
  - Use texture streaming
  - Implement level of detail
  - Reduce texture sizes
  - Use compressed formats
