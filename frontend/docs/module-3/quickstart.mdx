# Module 3 Quickstart Guide: Isaac Sim to Isaac ROS to Nav2 Integration

## Overview

This quickstart guide provides the essential steps to set up and run the complete Isaac Sim → Isaac ROS → Nav2 pipeline for bipedal humanoid navigation. Follow these steps to get your humanoid robot navigating in simulated environments quickly.

## Prerequisites

Before starting, ensure you have:
- Ubuntu 22.04 LTS with RTX GPU (RTX 3080 or better recommended)
- Isaac Sim 2023.1+ installed
- Isaac ROS packages built and installed
- Nav2 packages installed
- CUDA 12.0+ with appropriate drivers
- VRAM: Minimum 16GB (24GB+ recommended)

## Installation Steps

### 1. Set Up Isaac ROS Workspace

```bash
# Create Isaac ROS workspace
mkdir -p ~/isaac_ros_ws/src
cd ~/isaac_ros_ws

# Clone Isaac ROS packages (if not already done)
git clone -b ros2-humble https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_common.git src/isaac_ros_common
git clone -b ros2-humble https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_visual_slam.git src/isaac_ros_visual_slam
git clone -b ros2-humble https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_apriltag.git src/isaac_ros_apriltag
git clone -b ros2-humble https://github.com/NVIDIA-ISAAC-ROS/isaac_ros_occupancy_grid.git src/isaac_ros_occupancy_grid

# Install dependencies
rosdep install --from-paths src --ignore-src -r -y

# Build workspace
colcon build --symlink-install --packages-select \
  isaac_ros_common \
  isaac_ros_visual_slam \
  isaac_ros_apriltag \
  isaac_ros_occupancy_grid
```

### 2. Install Nav2 Packages

```bash
# Install Nav2 packages
sudo apt update
sudo apt install ros-humble-navigation2 ros-humble-nav2-bringup \
  ros-humble-nav2-common ros-humble-nav2-gui-plugins \
  ros-humble-nav2-map-server ros-humble-nav2-utils \
  ros-humble-nav2-amcl ros-humble-nav2-controller-server \
  ros-humble-nav2-planner-server ros-humble-nav2-recoveries \
  ros-humble-nav2-rotation-shim-controller \
  ros-humble-nav2-lifecycle-manager ros-humble-nav2-simple-commander \
  ros-humble-nav2-behavior-tree ros-humble-nav2-velocity-smoother \
  ros-humble-nav2-voxel-grid
```

### 3. Create Integration Package

```bash
# Create integration package
cd ~/isaac_ros_ws/src
ros2 pkg create --dependencies rclpy std_msgs geometry_msgs nav_msgs sensor_msgs \
  nav2_msgs visualization_msgs --destination-directory my_nav2_integration

# Build the new package
cd ~/isaac_ros_ws
colcon build --packages-select my_nav2_integration
```

## Configuration Setup

### 1. Create Isaac ROS Configuration

Create the Isaac ROS VSLAM configuration file:

```yaml
# ~/isaac_ros_ws/src/my_nav2_integration/config/isaac_vslam_params.yaml
/**:
  ros__parameters:
    # Enable IMU fusion for better pose estimation
    enable_imu_fusion: false  # Set to true if using IMU data
    # Use simulation time
    use_sim_time: true
    # Input topics from Isaac Sim
    image_left_topic: "/humanoid_robot/rgb_camera_left/image_raw"
    image_right_topic: "/humanoid_robot/rgb_camera_right/image_raw"
    camera_info_left_topic: "/humanoid_robot/rgb_camera_left/camera_info"
    camera_info_right_topic: "/humanoid_robot/rgb_camera_right/camera_info"
    # Output topics for Nav2
    pose_topic: "/isaac_ros/vslam/pose"
    twist_topic: "/isaac_ros/vslam/twist"
    # Tracking parameters
    tracking_frame: "humanoid_robot/rgb_camera_left_optical_frame"
    # Optimization parameters
    optimize_map_every_n_poses: 10
    # Map parameters
    min_num_stereo_features: 10
    # Performance parameters
    max_num_landmarks: 1000
    max_map_size: 1000
```

## Launch the Complete Pipeline

### 1. Create Integration Launch File

```xml
<!-- ~/isaac_ros_ws/src/my_nav2_integration/launch/isaac_ros_nav2_integration.launch.xml -->
<launch>
  <!-- Arguments -->
  <arg name="use_sim_time" default="true"/>
  <arg name="isaac_vslam_config" default="$(find-pkg-share my_nav2_integration)/config/isaac_vslam_params.yaml"/>
  <arg name="nav2_config" default="$(find-pkg-share my_nav2_integration)/config/nav2_params_humanoid.yaml"/>
  <arg name="map_file" default=""/>

  <!-- Isaac ROS Visual SLAM Node -->
  <node pkg="isaac_ros_visual_slam" exec="visual_slam_node" name="visual_slam" namespace="isaac_ros" output="screen">
    <param from="$(var isaac_vslam_config)"/>
    <param name="use_sim_time" value="$(var use_sim_time)"/>
  </node>

  <!-- Isaac ROS Occupancy Grid Node -->
  <node pkg="isaac_ros_occupancy_grid" exec="occupancy_grid_node" name="occupancy_grid" namespace="isaac_ros" output="screen">
    <param name="use_sim_time" value="$(var use_sim_time)"/>
    <param name="resolution" value="0.05"/>
    <param name="occupancy_grid_topic_name" value="/isaac_ros/occupancy_grid"/>
  </node>

  <!-- Nav2 Stack -->
  <include file="$(find-pkg-share nav2_bringup)/launch/navigation_launch.py">
    <arg name="use_sim_time" value="$(var use_sim_time)"/>
    <arg name="params_file" value="$(var nav2_config)"/>
    <arg name="autostart" value="true"/>
    <arg name="map" value="$(var map_file)"/>
  </include>

  <!-- Static TF publisher for Isaac Sim to ROS coordinate frames -->
  <node pkg="tf2_ros" exec="static_transform_publisher" name="isaac_sim_to_ros_tf" output="screen">
    <param name="use_sim_time" value="$(var use_sim_time)"/>
    <param name="x" value="0.0"/>
    <param name="y" value="0.0"/>
    <param name="z" value="0.0"/>
    <param name="qx" value="0.0"/>
    <param name="qy" value="0.0"/>
    <param name="qz" value="0.0"/>
    <param name="qw" value="1.0"/>
    <param name="frame_id" value="odom"/>
    <param name="child_frame_id" value="base_link"/>
  </node>

  <!-- RViz for visualization -->
  <node pkg="rviz2" exec="rviz2" name="rviz2" args="-d $(find-pkg-share nav2_bringup)/rviz/nav2_default_view.rviz" output="screen">
    <param name="use_sim_time" value="$(var use_sim_time)"/>
  </node>
</launch>
```

### 2. Launch the Complete System

```bash
# Source the workspace
source ~/isaac_ros_ws/install/setup.bash

# Launch the complete Isaac ROS-Nav2 integration
ros2 launch my_nav2_integration isaac_ros_nav2_integration.launch.xml use_sim_time:=true

# In another terminal, send a navigation goal
ros2 action send_goal /navigate_to_pose nav2_msgs/action/NavigateToPose "{pose: {header: {frame_id: 'map'}, pose: {position: {x: 1.0, y: 1.0, z: 0.0}, orientation: {w: 1.0}}}}"
```

## Troubleshooting Common Issues

### Issue 1: Poor Localization
- Verify Isaac Sim scene has sufficient visual features
- Check camera calibration parameters
- Ensure proper lighting conditions in simulation

### Issue 2: Navigation Failures
- Verify costmap inflation parameters are appropriate for humanoid size
- Check that robot footprint accounts for bipedal kinematics
- Ensure sufficient clearance for humanoid navigation

### Issue 3: Performance Issues
- Reduce Isaac ROS feature count if GPU resources are limited
- Lower Nav2 update frequencies for better performance
- Check that use_sim_time is properly synchronized
