## Lighting Configuration

### Types of Lights in Isaac Sim

Isaac Sim supports several types of lights, each with specific use cases:

#### Distant Light
Distant lights simulate light sources that are very far away, like the sun. They illuminate the entire scene with parallel rays.

**Properties**:
- **Intensity**: Brightness of the light (default: 500)
- **Color**: Color of the light (default: white [1,1,1])
- **Angle**: Angular size of the light source (affects softness of shadows)

**Use Cases**:
- Outdoor scenes
- Primary illumination
- Simulating sunlight

```python
# Create a distant light
from omni.isaac.core.utils.prims import create_prim

create_prim(
    prim_path="/World/Lighting/Sun",
    prim_type="DistantLight",
    attributes={
        "intensity": 1000,
        "color": [0.9, 0.9, 0.8],  # Slightly warm light
        "angle": 0.5
    }
)
```

#### Dome Light
Dome lights provide environmental illumination using HDR textures, creating realistic global illumination.

**Properties**:
- **Texture**: HDR image file for environment lighting
- **Intensity**: Overall brightness of the environment
- **Color**: Tint for the environment light

**Use Cases**:
- Indoor scenes
- Environmental lighting
- Reflections and ambient illumination

```python
# Create a dome light with HDR texture
create_prim(
    prim_path="/World/Lighting/Environment",
    prim_type="DomeLight",
    attributes={
        "intensity": 1.0,
        "color": [0.2, 0.2, 0.2],
        "texture:file": "path/to/environment.hdr"
    }
)
```

#### Rect Light
Rectangular area lights provide soft, even illumination from a defined rectangular area.

**Properties**:
- **Width/Height**: Dimensions of the light area
- **Intensity**: Brightness of the light
- **Color**: Color of the light
- **Enable Temperature**: Color temperature control

**Use Cases**:
- Studio lighting
- Indoor lighting
- Soft fill lighting

```python
# Create a rectangular area light
create_prim(
    prim_path="/World/Lighting/StudioLight",
    prim_type="RectLight",
    position=[0, 0, 3],
    attributes={
        "width": 2.0,
        "height": 1.0,
        "intensity": 800,
        "color": [1.0, 1.0, 1.0]
    }
)
```

#### Spotlight
Spotlights emit light in a cone shape with adjustable beam width and focus.

**Properties**:
- **Inner/Outer Cone Angle**: Defines the light distribution
- **Intensity**: Brightness of the light
- **Color**: Color of the light
- **Enable Temperature**: Color temperature control

**Use Cases**:
- Accent lighting
- Focused illumination
- Automotive headlights

```python
# Create a spotlight
create_prim(
    prim_path="/World/Lighting/Spotlight",
    prim_type="SpotLight",
    position=[0, -3, 2],
    orientation=[0.707, 0, 0, 0.707],  # Pointing downward
    attributes={
        "innerConeAngle": 0.5,
        "outerConeAngle": 0.7,
        "intensity": 600,
        "color": [1.0, 1.0, 1.0]
    }
)
```

### Performance Considerations for Lighting

To maintain the target performance of 30 FPS for basic scenes and 10 FPS for complex scenes:

1. **Limit the number of lights**: Use 1-3 main lights for basic scenes, up to 5-8 for complex scenes
2. **Optimize light properties**:
   - Use appropriate intensity values (avoid extremely high values)
   - Use shadow map resolution appropriate for your needs
   - Consider using light baking for static lighting
3. **Use IES profiles** for realistic light distribution
4. **Implement light culling** for scenes with many lights

## Physics Configuration

### Physics Scene Setup

The physics scene defines global physics properties for the entire simulation:

```python
# Configure the physics scene
from pxr import PhysxSchema, UsdPhysics

stage = omni.usd.get_context().get_stage()
physics_scene = UsdPhysics.Scene.Define(stage, "/World/PhysicsScene")

# Set physics properties
physics_scene.CreateGravityDirectionAttr().Set([0, 0, -1])
physics_scene.CreateGravityMagnitudeAttr().Set(9.81)
physics_scene.CreateTimestepAttr().Set(1.0/60.0)  # 60 FPS physics
```

### Rigid Body Configuration

Rigid bodies are objects that participate in physics simulation:

#### Basic Rigid Body Properties
- **Mass**: Mass of the object (kg)
- **Density**: Alternative to mass, calculated from volume
- **Center of Mass**: Point where forces are applied
- **Inertia**: Resistance to rotational motion

```python
# Create a rigid body
from omni.isaac.core.utils.prims import create_prim
from omni.isaac.core.utils.stage import add_physics_material

# Create an object
create_prim(
    prim_path="/World/Environment/Box",
    prim_type="Cube",
    position=[0, 0, 1],
    scale=[0.5, 0.5, 0.5]
)

# Add rigid body component
from pxr import UsdPhysics, PhysxSchema

stage = omni.usd.get_context().get_stage()
prim = stage.GetPrimAtPath("/World/Environment/Box")

# Apply rigid body properties
rigid_body = UsdPhysics.RigidBodyAPI.Apply(prim)
rigid_body.CreateMassAttr().Set(1.0)  # 1 kg
rigid_body.CreateLinearDampingAttr().Set(0.05)
rigid_body.CreateAngularDampingAttr().Set(0.05)

# Add collision
collision_api = UsdPhysics.CollisionAPI.Apply(prim)
```

#### Advanced Rigid Body Properties
- **Linear/Angular Damping**: Resistance to motion
- **Max Linear/Angular Velocity**: Speed limits
- **Sleep Threshold**: When to put object to sleep for performance
- **Stabilization**: Prevents jittering

### Collision Configuration

Collision shapes define how objects interact physically:

#### Types of Collision Shapes
1. **Box Collision**: Rectangular collision shape
2. **Sphere Collision**: Spherical collision shape
3. **Capsule Collision**: Capsule-shaped collision (good for characters)
4. **Mesh Collision**: Uses the object's mesh for collision
5. **Convex Hull**: Convex approximation of complex shapes

```python
# Add different collision shapes
from pxr import UsdPhysics

prim = stage.GetPrimAtPath("/World/Environment/MyObject")

# Box collision
collision = UsdPhysics.CollisionAPI.Apply(prim)
collision.CreateCollisionEnabledAttr().Set(True)

# For complex shapes, use convex decomposition
collision.CreateApproximationModelAttr().Set("convexDecomposition")
```

### Material Properties

Physics materials define surface properties for realistic interactions:

#### Surface Properties
- **Static Friction**: Resistance to starting motion
- **Dynamic Friction**: Resistance to continuing motion
- **Restitution**: Bounciness (0 = no bounce, 1 = perfectly elastic)

```python
# Create a physics material
physics_material = PhysxSchema.PhysxMaterial.Define(stage, "/World/Materials/DefaultMaterial")
physics_material.CreateStaticFrictionAttr().Set(0.5)
physics_material.CreateDynamicFrictionAttr().Set(0.4)
physics_material.CreateRestitutionAttr().Set(0.1)

# Apply to an object
collision_api = UsdPhysics.CollisionAPI.Apply(prim)
collision_api.CreateMaterialRel().SetTargets(["/World/Materials/DefaultMaterial"])
```

## Material Configuration for Realism

### Physically-Based Materials (PBR)

Isaac Sim uses Physically-Based Rendering materials for realistic appearance:

#### Material Properties
- **Albedo (Base Color)**: The base color of the material
- **Roughness**: How rough or smooth the surface appears
- **Metallic**: How metallic the surface appears (0-1)
- **Normal Map**: Surface detail without geometry
- **Occlusion**: Ambient occlusion for contact shadows
- **Emissive**: Light-emitting surfaces

```python
# Create a PBR material
from omni.particle.system.core import MaterialAPI
from pxr import UsdShade

# Create material prim
material_path = "/World/Materials/ExampleMaterial"
material = UsdShade.Material.Define(stage, material_path)

# Create shader
shader = UsdShade.Shader.Define(stage, material_path + "/Shader")
shader.CreateIdAttr("OmniPBR")

# Set material properties
shader.CreateInput("diffuse_color", Sdf.ValueTypeNames.Color3f).Set([0.8, 0.2, 0.2])  # Red
shader.CreateInput("roughness", Sdf.ValueTypeNames.Float).Set(0.3)
shader.CreateInput("metallic", Sdf.ValueTypeNames.Float).Set(0.0)
shader.CreateInput("clearcoat", Sdf.ValueTypeNames.Float).Set(0.0)

# Bind material to geometry
binding_api = UsdShade.MaterialBindingAPI(prim)
binding_api.Bind(material)
```

### Texture Mapping

Apply textures to materials for detailed surfaces:

```python
# Add texture to material
from pxr import Sdf

# Create texture sampler
texture_shader = UsdShade.Shader.Define(stage, material_path + "/Texture")
texture_shader.CreateIdAttr("UsdUVTexture")
texture_shader.CreateInput("file", Sdf.ValueTypeNames.Asset).Set("path/to/texture.png")

# Connect texture to material property
shader.GetInput("diffuse_color").ConnectToSource(texture_shader, "rgb")
```

## Performance Optimization

### Lighting Optimization
1. **Use light linking** to limit which objects each light affects
2. **Optimize shadow resolution** - use appropriate settings for your needs
3. **Use light baking** for static lighting where possible
4. **Implement light culling** for lights outside the camera view

### Physics Optimization
1. **Use appropriate collision shapes** - simpler shapes for performance
2. **Implement sleeping** for objects at rest
3. **Use instancing** for multiple similar objects
4. **Optimize physics timestep** - balance accuracy and performance

Set up realistic lighting and physics properties for a room scene to achieve photorealistic rendering and accurate physics simulation.

### Steps

2. **Lighting Configuration**:
   - Add a dome light with an HDR environment texture for ambient lighting

   - Adjust light intensities and shadow settings as needed
   - Verify physics simulation behaves correctly

### Sample Configuration Code

```python
# Complete room scene setup
import omni
from omni.isaac.core.utils.prims import create_prim
from pxr import UsdPhysics, PhysxSchema

# Get stage
stage = omni.usd.get_context().get_stage()

# Setup physics scene
physics_scene = UsdPhysics.Scene.Define(stage, "/World/PhysicsScene")
physics_scene.CreateGravityDirectionAttr().Set([0, 0, -1])
physics_scene.CreateGravityMagnitudeAttr().Set(9.81)

create_prim(
    prim_path="/World/Lighting/Environment",
    prim_type="DomeLight",

        "texture:file": "path/to/indoor_environment.hdr"

rigid_body = UsdPhysics.RigidBodyAPI.Apply(chair_geom.GetPrim())

rigid_body.CreateLinearDampingAttr().Set(0.05)
rigid_body.CreateAngularDampingAttr().Set(0.1)

collision_api.CreateCollisionEnabledAttr().Set(True)
```

## Troubleshooting Common Issues

### Lighting Issues
- **Dark scenes**: Check if dome light intensity is too low or if there are no primary lights
- **Overexposed scenes**: Reduce light intensities or adjust camera exposure
- **Artifacts in shadows**: Increase shadow map resolution or adjust light angles
- **Performance issues**: Reduce the number of lights or lower shadow quality

### Physics Issues
- **Objects falling through surfaces**: Check collision properties and physics materials
- **Unrealistic bounces**: Adjust restitution values in physics materials
- **Objects sliding too much**: Increase friction values
- **Jittery motion**: Check mass properties and consider increasing damping

### Material Issues
- **Materials appear black**: Check texture paths and material connections
- **Incorrect metallic appearance**: Verify metallic and roughness values
- **Missing reflections**: Ensure proper lighting and material setup
