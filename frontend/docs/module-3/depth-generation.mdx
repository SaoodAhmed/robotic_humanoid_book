# Depth Map Generation Process

## Overview

Depth map generation is a critical component of synthetic dataset creation, providing 3D spatial information for each pixel in the scene. Depth maps are essential for various computer vision tasks including 3D reconstruction, object detection, and scene understanding. In Isaac Sim, depth maps can be generated with high accuracy using the Replicator framework, providing valuable ground truth data for training depth estimation models.

- Optimize depth generation for performance targets

## Depth Map Fundamentals

### Depth Representation

Depth maps encode distance information for each pixel in the scene:

#### Types of Depth Maps
1. **Z-Depth**: Distance along the camera's Z-axis (orthogonal depth)
2. **Distance to Image Plane**: Euclidean distance from camera to surface point
3. **World Coordinate Depth**: Actual 3D coordinates in world space

#### Depth Map Properties
- **Resolution**: Matches the RGB image resolution
- **Bit Depth**: Typically 16-bit or 32-bit floating point
- **Distance Range**: Minimum to maximum measurable distance
- **Units**: Usually meters or millimeters

### Depth Accuracy Factors

The accuracy of generated depth maps depends on:
- Camera properties (focal length, aperture)
- Scene geometry and complexity
- Rendering resolution
- Anti-aliasing settings

## Depth Generation Pipeline

### Basic Depth Generation Setup

```python
import omni.replicator.core as rep

def setup_depth_generation():
    """Set up complete depth map generation pipeline"""

    # Create camera and render product
    camera = rep.create.camera()
    render_product = rep.create.render_product(camera, resolution=(1920, 1080))

    # Attach multiple annotators
    rgb_annotator = rep.AnnotatorRegistry.get_annotator("rgb")
    rgb_annotator.attach(render_product)

    depth_annotator = rep.AnnotatorRegistry.get_annotator("distance_to_image_plane")
    depth_annotator.attach(render_product)

    # Configure writer to output both RGB and depth
    writer = rep.WriterRegistry.get("BasicWriter")
    writer.initialize(
        output_dir="output/depth_dataset",
        rgb=True,
        depth=True,
        bounding_box_2d_tight=True
    )

    return writer
```

```python
def setup_multi_modal_generation():
    """Set up generation with RGB, depth, and semantic annotations"""

    camera = rep.create.camera()
    render_product = rep.create.render_product(camera, resolution=(1920, 1080))

    # Attach all required annotators
    annotators = {

        'semantic': rep.AnnotatorRegistry.get_annotator("semantic_segmentation"),
        'instance': rep.AnnotatorRegistry.get_annotator("instance_segmentation")
    }

    for name, annotator in annotators.items():

    writer = rep.WriterRegistry.get("BasicWriter")
    writer.initialize(
        output_dir="output/multi_modal_dataset",
        rgb=True,
        depth=True,
        semantic_segmentation=True,
        instance_segmentation=True
    )

    return writer
```

## Depth Quality and Accuracy

### Depth Accuracy Validation

Validate depth map accuracy against ground truth:
```python
import numpy as np
import cv2

def validate_depth_accuracy(depth_path, expected_distance, tolerance=0.01):
    """Validate depth accuracy at a known point"""

    # Load depth map
    depth_map = cv2.imread(depth_path, cv2.IMREAD_UNCHANGED)

    if depth_map is None:
        return False, "Invalid depth file"

    # For validation, we'll check the center pixel
    h, w = depth_map.shape
    center_depth = depth_map[h//2, w//2]

    # Check if within tolerance
    if abs(center_depth - expected_distance) <= tolerance:
        return True, f"Depth accurate: {center_depth:.3f}m vs {expected_distance:.3f}m"
    else:
        return False, f"Depth inaccurate: {center_depth:.3f}m vs {expected_distance:.3f}m (diff: {abs(center_depth - expected_distance):.3f}m)"

def analyze_depth_distribution(depth_path):
    """Analyze depth map distribution and statistics"""

    depth_map = cv2.imread(depth_path, cv2.IMREAD_UNCHANGED)
    if depth_map is None:
        return None

    # Calculate statistics
    stats = {
        'min': np.min(depth_map),
        'max': np.max(depth_map),
        'mean': np.mean(depth_map),
        'std': np.std(depth_map),
        'valid_pixels': np.count_nonzero(depth_map > 0),
        'total_pixels': depth_map.size
    }

    # Calculate percentage of valid depth values
    stats['valid_percentage'] = (stats['valid_pixels'] / stats['total_pixels']) * 100

    return stats
```

### Sample Implementation

```python
import omni.replicator.core as rep
import numpy as np
import cv2
import os

def create_depth_generation_pipeline():
    """Create a complete depth generation pipeline"""

    # Create scene with objects at different depths
    for i in range(5):
        # Create objects at increasing distances
        distance = 2 + i * 2  # 2m, 4m, 6m, 8m, 10m
        rep.create.cube(
            prim_path=f"/World/Environment/Object{i}",
            position=[0, 0, 1],
            scale=[0.5, 0.5, 0.5]
        ).scale(position=[i * 0.5, 0, 0])  # Slightly offset in X

    # Create camera
    camera = rep.create.camera(
        prim_path="/World/Sensors/DepthCamera",
        position=[0, -1, 1.5]  # 1m away from first object
    )

    # Create render product
    render_product = rep.create.render_product(camera, resolution=(1280, 720))

    # Attach annotators
    rgb_annotator = rep.AnnotatorRegistry.get_annotator("rgb")
    rgb_annotator.attach(render_product)

    depth_annotator = rep.AnnotatorRegistry.get_annotator("distance_to_image_plane")
    depth_annotator.attach(render_product)

    # Configure writer
    writer = rep.WriterRegistry.get("BasicWriter")
    writer.initialize(
        output_dir="output/depth_pipeline_test",
        rgb=True,
        depth=True
    )

    # Execute generation
    with rep.trigger.on_frame(num_frames=10):
        writer.write()

    print("Depth generation pipeline executed successfully!")
```

## Troubleshooting Common Depth Issues

### Depth Accuracy Issues
- **Incorrect depth values**: Check camera clipping range settings
- **NaN or infinite values**: Verify scene geometry and camera position
- **Inconsistent depth**: Check for overlapping objects or geometry issues

### Performance Issues
- **Slow generation**: Depth generation is typically fast, but complex scenes may slow it down
- **Memory issues**: Depth maps are generally smaller than RGB images

### Technical Issues
- **No depth files**: Verify annotator attachment and writer configuration
- **Black depth maps**: Check if objects are within clipping range
- **Wrong format**: Ensure proper bit depth configuration

## Best Practices

1. **Proper clipping ranges**: Set near/far clipping to match scene requirements
2. **Consistent units**: Use meters for consistency with other Isaac Sim components
3. **Validation**: Always validate depth accuracy with known distances
4. **Resolution matching**: Ensure depth resolution matches RGB for alignment
5. **Multi-sensor coordination**: When using multiple sensors, ensure proper timing
6. **Quality assessment**: Regularly analyze depth distribution and statistics

## Performance Targets

For depth map generation:
- **Basic scenes**: Maintain 30 FPS with 1920x1080 resolution
- **Complex scenes**: Maintain 10 FPS with 1920x1080 resolution
- **Accuracy**: Sub-centimeter accuracy for close objects, meter-level for distant objects
- **Multi-sensor**: Support up to 50 concurrent depth sensors per simulation
- **Multi-user**: Support up to 10 simultaneous student sessions
